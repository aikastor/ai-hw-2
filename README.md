Ответы на русском и английском по официальным источникам КГТУ, со ссылками на документы.

## Запуск для преподавателя через Docker

Нужны **Docker Desktop** (либо Docker Engine с Compose), интернет и собственный ключ Groq. Python и Ollama отдельно устанавливать не нужно.

```sh
git clone https://github.com/aikastor/ai-hw-2.git
cd ai-hw-2
cp rag-kstu/.env.example rag-kstu/.env
```

В Windows PowerShell используйте `Copy-Item` вместо `cp`, если требуется. Откройте `rag-kstu/.env` и укажите свой `GROQ_API_KEY`, затем:

```sh
docker compose up --build
```

Откройте **http://localhost:8501** после готовности сервисов. Первый запуск скачивает образы и модель bge-m3 (около 1,2 ГБ), затем создаёт индекс. Повторные запуски используют сохранённые модель и базу.

Для остановки — Ctrl+C или `docker compose down`. Не добавляйте `-v`, если хотите сохранить данные. Docker использует ресурсы вашего компьютера; приложение не размещается в облаке.

## Данные и технологии

Compose запускает Ollama, FastAPI со встроенной локальной Qdrant и Streamlit. Поиск объединяет BM25 и bge-m3. Groq генерирует и проверяет ответы; выбранные источники и сообщения передаются этому внешнему сервису. Ключ доступен только API.

Каталоги `rag-kstu/data/` и `data/` содержат проверенные материалы для воспроизводимой сборки. Сбор сайта и OCR повторять не нужно. Секреты, виртуальные окружения, модель и сгенерированная база исключены из Git и контекста сборки.

Покрытие неполное: общеуниверситетские пороги ОРТ и квоты грантов на бакалавриат ещё не подтверждены. Проверочные вопросы описывают ожидаемое поведение, а не гарантируют прохождение всех тестов.
